🧠 Concepts Covered
Switch-Case

The switch statement is useful when a program needs to choose between multiple possible options.

switch(choice)
{
    case 1:
        // Option 1
        break;

    case 2:
        // Option 2
        break;

    default:
        // Invalid choice
}

Break Statement

The break statement terminates the current case and prevents execution from continuing into the following cases.

Compile any program using GCC:

Run it:

Linux / macOS

Windows
