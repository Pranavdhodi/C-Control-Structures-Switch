🚀 C Control Structures & Switch Case

A collection of simple and practical C programs demonstrating control structures, decision-making, and switch-case statements.

📌 Overview

This repository contains Lab 4 C programming exercises focused on understanding control flow and decision-making in C.

The programs use practical examples such as calculators, billing systems, discounts, area calculations, and weekdays to demonstrate different control structures.

| File                | Description                                    |
| ------------------- | ---------------------------------------------- |
| `calculator.c`      | Basic arithmetic calculator                    |
| `area.c`            | Area calculation                               |
| `areabreak.c`       | Area calculation using switch-case and `break` |
| `discount.c`        | Discount calculation                           |
| `electricitybill.c` | Electricity bill calculation                   |
| `internetbill.c`    | Internet bill calculation                      |
| `telephonebill.c`   | Telephone bill calculation                     |
| `weekdays.c`        | Displays a weekday based on user input         |

💻 Example
switch (choice)
{
    case 1:
        printf("Option 1 selected");
        break;

    case 2:
        printf("Option 2 selected");
        break;

    default:
        printf("Invalid choice");
}

⚙️ How to Run
Clone the repository
git clone https://github.com/Pranavdhodi/C-Control-Structures-Switch.git
cd C-Control-Structures-Switch

Compile
gcc calculator.c -o calculator

Run

Linux / macOS:

./calculator


Windows:

calculator.exe


Replace calculator.c with any other .c file you want to run.

🎯 Learning Objective

The purpose of this repository is to practice C control structures and switch-case statements through small, practical programs.

These examples are suitable for beginners who are learning how to build decision-based programs in C.
